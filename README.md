# MG Compressor — pobieranie

Desktopowy program do wsadowej kompresji, zmiany rozmiaru i konwersji zdjęć. Przetwarza foldery lokalnie i działa bez internetu.

[Pobierz najnowsze wydanie MG Compressor](https://github.com/GasekStudio/MG-Compressor-downloads/releases/latest)

| System | Który plik wybrać |
| --- | --- |
| Windows 10 i 11, x64 | Plik z końcówką `Windows-x64-Setup.exe`. Otwórz dwuklikiem. |
| Fedora i inne dystrybucje Linux x86-64 z Flatpakiem | Plik `.flatpak`. Na Fedorze otwórz dwuklikiem w Oprogramowaniu GNOME. |
| Fedora 45, x86-64 | Podpisany pakiet `fc45.x86_64.rpm` i klucz `MG-Compressor-RPM.asc`. Instrukcja jest w opisie wydania. |

Źródła odpowiadające instalatorom są dostępne razem z każdym wydaniem. MG Compressor jest modyfikacją Caesium Image Compressor 2.8.5 udostępnianą na licencji GNU GPL v3.
