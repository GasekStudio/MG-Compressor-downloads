# MG Compressor — pobieranie

Desktopowy program do wsadowej kompresji, zmiany rozmiaru i konwersji zdjęć. Przetwarza foldery lokalnie i działa bez internetu.

| System | Co pobrać | Wersja |
| --- | --- | --- |
| Linux (Mint, Fedora, Ubuntu i inne x86-64 z Flatpakiem) | [`MG-Compressor.flatpakref`](https://github.com/GasekStudio/MG-Compressor-downloads/releases/download/v1.1.0/MG-Compressor.flatpakref): otwórz dwuklikiem i wybierz **Zainstaluj**. Program aktualizuje się sam (za Twoją zgodą). | [1.1.0](https://github.com/GasekStudio/MG-Compressor-downloads/releases/tag/v1.1.0) |
| Windows 10 i 11, x64 | [`MG-Compressor-1.0.0-Windows-x64-Setup.exe`](https://github.com/GasekStudio/MG-Compressor-downloads/releases/download/v1.0.0/MG-Compressor-1.0.0-Windows-x64-Setup.exe): otwórz dwuklikiem. | [1.0.0](https://github.com/GasekStudio/MG-Compressor-downloads/releases/tag/v1.0.0) |

Gdy dwuklik na `.flatpakref` nie działa, w terminalu: `flatpak install --from https://github.com/GasekStudio/MG-Compressor-downloads/releases/download/v1.1.0/MG-Compressor.flatpakref`.
Kto ma wersję 1.0.0 na Linuksie, instaluje 1.1.0 raz w ten sam sposób; od 1.1.0 aktualizacje przychodzą same.

Źródła odpowiadające instalatorom są dostępne razem z każdym wydaniem. MG Compressor jest modyfikacją Caesium Image Compressor 2.8.5 udostępnianą na licencji GNU GPL v3.
